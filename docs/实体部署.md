# 小飞鱼实体部署 · 施工文档

建档：2026-11-14。这份文档是"灵魂与身体分离"这条架构铁律的落地接线图。

准入门槛与产品形态分层见 `实体准入清单.md`。阶段 1 完成局域网接线，不等于已经满足实体化的前置条件。

## 一、分层事实

她的记忆、人格、行为状态、日记与账单全部在电脑上的 Python 进程与 SQLite 文件里。身体只负责两件事：把画面显示出来、把输入送回去。换身体不需要迁移人格，也不需要换模型厂商。

## 二、阶段 0：电器模式（已完成，零成本）

- `大肥鱼看门狗.pyw`：每 15 秒体检 8765 / 8080 / 11434，进程死了自动拉起。复活能力在 2026-11-08 实测通过。
- `安装开机自启.bat`：需要主人双击一次。本会话写入系统启动文件夹的内容会被环境回滚，2026-11-14 复查启动文件夹仍只有 `desktop.ini`。
- `/monitor`：服务健康、Token 账单、对话量、记忆生态、提醒送达、心情曲线。
- `自检.py`：语法、协议不变量、动态起页面、截图级"鱼是否可见"。

## 三、阶段 1：旧手机 / 平板当身体（本次交付，零成本）

### 接线契约

| 项目 | 值 |
|---|---|
| 页面 | `http://<电脑局域网IP>:8080/脑袋-v0.1.html?k=<令牌>` |
| 大脑通道 | `ws://<同一主机>:8765/ws?k=<令牌>` |
| 令牌 | 首次实体模式启动生成，存 `大肥鱼服务端/.lan_token`，之后复用 |
| 默认状态 | 未设 `DFY_LAN` 时两个服务都只听回环地址，令牌层完全不启用 |
| 放行规则 | 本机回环免令牌；其它来源必须带对令牌；WS 错令牌以 4401 关闭 |
| 页面服务 | 实体模式改走 `实体页面服务.py`，白名单只放行页面与 `形象/` 素材 |

### 操作步骤

1. 手机与电脑连同一个 WiFi。
2. 双击 `实体模式.bat`。它先运行 `实体模式准备.py` 清理仍绑在回环地址的旧服务，再按局域网模式重启；从普通模式切换时不需要手工关窗口。这一步在 2026-11-14 实测通过。
3. 用手机扫 `手机接入.png`，或手工输入 `局域网接入.txt` 里的地址。
4. 手机上打字跟她说话。

### 硬限制：麦克风

浏览器只在安全上下文里提供 `getUserMedia()`，也就是 HTTPS、`file://` 或 `localhost`；普通 HTTP 局域网地址下 `navigator.mediaDevices` 是 `undefined` (MDN, "MediaDevices: getUserMedia() Method")。因此阶段 1 的手机身体**能看、能听她的语音、能打字，不能用语音输入**。语音回复属于音频播放，不受这条限制。要让手机也能开口说话，需要给页面与 WS 都配 HTTPS / WSS 并让设备信任证书，这一层本次没有做。

### 安全边界（必须先讲清楚）

- 实体模式会把 8080 与 8765 暴露到局域网。普通 `http.server` 会把整个项目目录一起交出去，里面含 `keys.local.json`、`soul.db`、`memory_stream.db`。本次改成白名单静态服务，实测这些路径与目录穿越变体全部返回 403。
- 令牌是局域网里的一扇门，不是加密。同一 WiFi 内拿到链接的人可以读她的记忆与监测台，别把链接转发出去。
- 路由器没做端口映射时，链接只在家里有效。本文档没有验证过任何公网暴露场景。
- `keys.local.json` 不通过这两个端口提供。
