# 实时互动与"训练" · 事实、边界与本轮施工

建档：2026-11-14。这份文档回答两个问题：为什么她还不像打电话那样实时；给她"训练一下"到底能做什么。

## 一、实时管线：零件其实大半都在

我逐环节查了代码，下面这些是**已经实现**的，不是计划。

| 环节 | 现状 |
|---|---|
| 语音识别 | `continuous=true`、`interimResults=true`，浏览器连续识别并给出中间结果 |
| 大模型 | `stream=True`，多供应商首 token 竞速（`race_first_token`），逐块下发 `chunk` |
| 分句抢跑 | 按标点切句（`_cut_sentence`），首句优先（`QUICK_FIRST`），不等全文 |
| 语音合成 | `TTS_WORKERS = 2`，两个 worker 并行合成，按编号顺序发包 |
| 播放 | 前端 `audioQ` 排队，`audioCursor` 对齐，字幕逐字跟声 |
| 打断 | 用户发话触发 `stopAudio()`，服务端有"等等等等"提示与 45 秒限流 |

**实测延迟数据**：`dbg.log` 里单段 TTS 耗时在 1.87 秒到 8.19 秒之间；历史记录里一轮真实对话从输入到开口约 7.7 秒；本地脑冷启动独立首答 17.7 秒（*大肥鱼-交接文档*）。

## 二、那为什么还是"不实时"

**两个具体缺口，都是查出来的事实：**

1. 前端 `rec.onresult` 里原本写着 `if (!r.isFinal) continue;`——**中间识别结果被直接丢掉**。你说话的整整几秒里，她没有任何反应，等你说完才开始处理。
2. 全链路没有分段计时。首 token、首段音频、总耗时都没有留痕，所以"慢在哪"只能靠猜。

**本轮补的两项（R 编号）：**

- **R1 延迟可观测**：服务端记录每轮的 `first_token`、`first_audio`、`total` 与句数，写进 `dbg.log` 与 `/monitor/data` 的 `latency_recent`；监测台新增「实时延迟」卡片，最近 6 轮逐条可查。
- **R2 提前反应**：中间识别结果到达时，她立刻切成"在听"的表情并抬头（1500 毫秒自动过期，不写残留字幕）。这条零 API、纯本地，服务没连上也生效。

**仍然做不到的**：像真人打电话那样随说随接、端到你一句我一句不等待。原因不是缺某个库，而是每一段都有物理耗时——识别要等最终结果与噪声守门、模型首 token 要网络往返、每段 TTS 要 2~8 秒。我没有实测过把这些压到某个目标值，也不写目标数字。真正全双工还需要 VAD（判断你说完没有）与边说边合成的连续音频流，这两项本次没有做。

## 三、"训练"要先分清两件事

**改权重的训练（微调）**：公开资料给出的 7B 模型门槛是 LoRA 约 16GB 显存、QLoRA（4bit）约 6~16GB 显存，且推荐清单都是 NVIDIA 独立显卡（GPU.fm, "QLoRA vs LoRA"；简米科技, "微调一个模型需要多大显存"）。我在本机实测到的显卡是 **AMD Radeon 780M 核显**、内存 19.8GB、CPU 为 AMD Ryzen 7 8745H，没有独立显卡。核显能否通过 ROCm/DirectML 跑这类训练，**我没有查证，结果是不知道**；云端厂商是否对我们用的模型开放微调接口，我也没有查证。数据侧：库里有 317 条用户消息、162 条她的回复，其中相邻问答对 153 组，平均每条回复 30.7 字——这个量级能不能支撑微调，我同样没有验证。

**不改权重的训练（本轮做的）**：把她自己说过的话当教材。

- **T1 风格教材**：`soul.style_examples()` 从 153 组真实相邻问答里打分挑 5 组，过滤测试污染、标签词泄漏（`干饭～` 这类）、英文碎片与固定开场，作为少样本注入每轮提示词。教材全部来自本地数据库，按天缓存，删掉缓存即回到默认。
- **T2 负反馈闭环**：工具条新增「这句不像她」。点一下，服务端把最近一句她的回复记进 `bad_replies` 并清空教材缓存，下次重算时把它排除。她越被纠正，教材越像她。

**实测**：教材产出 5 组，收紧过滤前后对比确认标签词泄漏样本已被排除；提示词里确实出现「她自己的说法」段落；反馈通道回包 `feedback_ok`，负样本入库、缓存清空；`/monitor/data` 返回 `latency_recent` 字段。

**必须说清的边界**：这套东西改变的是"她看到的上下文"，不是模型权重。我不声称她的回复已经变好——本轮没有跑过真实对话来验证效果，这一项标注为**未验证**。
