# 小飞鱼大脑架构 v1.0

> 2026-11-08 立项。本文档是大肥鱼/小飞鱼智能系统的设计基准：
> 所有后续开发（本地化、实体化、开源）以此为契约。
> 事实部分全部来自当前运行代码（server.py / soul.py / 脑袋-v0.1.html），
> 标注「计划」的部分是路线图，尚未实现。

---

## 〇、设计哲学（五条铁律）

1. **灵魂与身体分离** —— 记忆/性格/行为是纯 Python+SQLite+浏览器，不依赖任何硬件。换身体（平板/树莓派/实体）只需换表达层。
2. **记忆是生命，不是档案** —— 记忆遵循赫布学习（被想起就加强）与艾宾浩斯遗忘（不被想起就淡去）。她说出口的记忆强化 15%，没被想起的按留存曲线衰减。记忆是活的生态系统。
3. **韧性三层递降** —— 云端智能（72B）→ 本地智能（ollama 7B）→ 反应式生存（内置短语）。无论断网、欠费、接口爆炸，她永远不哑。
4. **随机性即生命感** —— 一切自发行为带随机抑制（「想起」35% 不触发、巡游目标随机、主动搭话间隔抖动）。定时器太规律就是脚本。
5. **一切状态本地持有** —— 记忆库、日记、画像全在本地磁盘。她是"住在这里的"，不是"登录进去的"。

## 一、七层架构

```
┌─ 感官层 ──────────────────────────────────────────┐
│ 语音识别(浏览器SR) · 摄像头视线 · 文本输入          │
├─ 守门层 ──────────────────────────────────────────┤
│ 噪声置信度门 · 回声滤网 · 同句去重 · 回合制打断协议 │
├─ 认知层（三脑协同）───────────────────────────────┤
│ 实时主脑: 硅基Qwen2.5-72B（竞速优先，~0.6s首字）    │
│ 深思脑:   英伟达minimax-m3.1（后台画像/反思，慢而深）│
│ 本地脑:   ollama qwen2.5-7B（断网兜底，计划中）     │
│ 生存层:   内置反应短语（全挂时也不断气）            │
├─ 记忆层 ──────────────────────────────────────────┤
│ 神经链(nodes+links): 赫布学习+激活扩散+遗忘曲线     │
│ 对话流水 · 人物画像 · 事实 · 里程碑 · 日记(桌面双写)│
│ 状态: 心情/白饭/作息 —— 【此刻】时钟注入每轮上下文  │
├─ 行为层 ──────────────────────────────────────────┤
│ ACT状态机: 巡游/趴顶/游近/游远/打盹/整理/哼歌       │
│ 游动系统v3: ±160px+缩放1.18/0.9+转身倾斜           │
│ 「想起」: 独处时自主翻记忆讲旧事（赫布强化闭环）    │
│ 主动搭话: 空闲随机，被打断后计算退避                │
├─ 表达层 ──────────────────────────────────────────┤
│ TTS: 硅基CosyVoice克隆音色 + 三层DSP净化           │
│ 字幕: 与音频同一时钟逐字同步                        │
│ 表情: 情绪标签→rig 33层立绘表情/动作映射            │
├─ 韧性层 ──────────────────────────────────────────┤
│ 看门狗(15s体检自动复活) · 禁缓存 · 失败红字横幅     │
│ 日记随聊随写 · 服务自愈 · 截图级可见性自检          │
└───────────────────────────────────────────────────┘
```

## 二、一次对话的完整旅程（数据流）

1. 你开口 → 浏览器 SR 转文字 → **守门层**（置信度≥0.6~0.75、非纯语气词、非回声、非 5 秒内重复）
2. 文本包（带回合号）→ 服务端 → **打断协议**（真打断才打断；45 秒内不重复人性提示）
3. **记忆检索**：激活扩散 + 语义相似 + 留存曲线 → 相关记忆进上下文；**【此刻】时钟**强制注入（报时禁止翻旧账）
4. **认知层**：build_messages（人格+状态+画像+记忆+最近对话）→ 竞速 72B → 流式出字
5. **边说边合成**：切一句丢一句给 TTS（双工人并行），音频段+逐字字幕同频下发
6. 回复完成 → log 对话 → 记忆强化 → **日记随聊随写**（桌面同步）→ 状态结算（白饭/心情）

## 三、记忆的生态循环（核心创新点）

```
发生 → 写入 nodes（强度 S 初始 1.0）
被检索 → strength +0.5（艾宾浩斯留存 = exp(-天数/S)）
被「想起」讲出 → strength +0.15，联想边 weight +0.2
长期不被提起 → 留存衰减，检索权重下降
```
记忆的"生老病死"全部由交互自然驱动，无人工清理。星图页面是这套循环的可视化。

## 四、韧性矩阵（故障 × 应对）

| 故障场景 | 应对 | 状态 |
|---|---|---|
| 断网/云端全挂 | 本地脑 ollama 顶上 | 代码就绪，模型安装中（计划） |
| TTS 失败 | 重试一次→静音跳过，字幕仍走 | 已实现 |
| TTS 音质毛刺 | 客户端+服务端双层 DSP 净化 | 已实现（毛刺 -91%→0） |
| 服务崩溃 | 看门狗 15 秒复活 | 已实现（实测） |
| 形象加载失败 | 红字横幅提示强刷 | 已实现 |
| 她正说话你插话 | 回合制打断+人性化接话 | 已实现 |
| 环境噪声 | 置信度门+语气词黑名单 | 已实现 |
| 凌晨服务不在场 | 日记随聊随写 | 已实现 |

## 五、进化路线

- **v1.5（近期）**：Whale-Plus 爬窗行为移植；星图与「想起」联动（她讲记忆时星图对应节点亮起）；自检继续扩容
- **v2（本地智能，配合阶段 2 硬件）**：ollama 常驻为主脑（离线优先），云端降为增强；记忆压缩（旧的自动摘要合并）
- **v3（实体化，阶段 3）**：ACT 状态机 → 舵机编排层；场景 = 实体空间；麦克风阵列硬件降噪
- **开源契约**：代码 MIT；素材 CC BY-NC-SA（署名上善无形/ZipZipPipe，相同方式共享）；本文档随包发布

## 六、约束与已知边界（诚实清单）

- 英伟达接口当前 30s 级延迟，仅胜任后台深思（实测）
- 硅基克隆音色有底噪，三层净化后仍有残留（用户可感知度待定）
- 本地 7B 模型智力低于 72B，兜底模式下会变"笨"但不哑（权衡已接受）
- 本会话环境无法验证持久服务，看门狗的长期表现由日常运行检验
