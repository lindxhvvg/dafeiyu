# 大肥鱼开源生态调研（2026-11-07）

## 一、直接可用（同款项目，MIT 代码）

1. **dsh-pet**（github.com/PC2005-cloud/dsh-pet）——我们这条鱼的原型项目，MIT（代码），5200+ 星
   - 100+ 段动画资产、物理拖拽、余额展示、待办提醒、睡觉说梦话
   - 可直接参考/借鉴的实现（MIT 允许）
2. **dsh-pet-indesktop**（github.com/MerZlin/dsh-pet-indesktop）——Python+PySide6 独立版，2900+ 星
   - 默认接 DeepSeek 官方 API（deepseek-v4-flash）——另一个脑子选项
   - 热加载角色：manifest.json + videos 目录，改完即用

## 二、形象包（素材层，注意 CC BY-NC-SA）

3. **Coopanion-DeepSeek-Whale-Plus**（github.com/xuejianxianzun/Coopanion-DeepSeek-Whale-Plus）
   - 官方大肥鱼形象的修改版：**可飞行、游泳、抱窗边爬、站窗口顶**——正对我们"让她动起来"的方向
   - 注意：衍生自 CC BY-NC-SA 素材，个人使用 OK，商用需原作者授权
4. GitHub 搜索 "Coopanion 形象" 可持续找到社区形象包（GPT 龙娘、Claude 娘等）

## 三、大脑选项

5. **DeepSeek 官方 API**（api.deepseek.com，deepseek-v4-flash）——dsh-pet-indesktop 默认接入，便宜+快
6. 本地离线脑：DeepSeek-R1 蒸馏版（ollama），7B 量化约 4.5GB 内存——符合"部署到线下"，780M 核显跑 7B Q4 可行但速度待实测

## 四、TTS 自托管备选（治电流音的终极方案）

7. **GPT-SoVITS**（MIT，62.9k 星）——5 秒音频克隆，Windows 有整合包；无 GPU 时 CPU 推理较慢
8. **CosyVoice**（Apache-2.0，阿里开源）——我们现在用的接口背后就是这个模型，可自托管
9. **VoxCPM**（Apache-2.0，39.3k 星）——8GB 显存可跑 48kHz；核显笔记本只能 CPU，速度待测
10. 结论：无独显笔记本上自托管 TTS 速度存疑，短期保持 API；换 GPU 后 GPT-SoVITS 是首选
