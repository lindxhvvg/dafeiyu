# Character artwork and 3D assets license

This repository separates two kinds of material:

- Original code and original written documents: **MIT** (see `LICENSE`).
- Files in `3d/`: **CC BY-NC-SA 4.0** (see `3d/LICENSE.md`), because they are
  adaptations of a community character.

The runtime 2D character layers are **not distributed** in this repository.

## What the license requires

CC BY-NC-SA 4.0 Section 2(a)(1) permits producing and sharing Adapted
Material for NonCommercial purposes only. Section 3(a) requires attribution,
an indication of changes, and a license notice. Section 3(b) requires an
Adapter's License with the same License Elements (BY, NC, SA), version 4.0 or
later, or a BY-NC-SA Compatible License, when Adapted Material is shared.
`3d/LICENSE.md` is that Adapter's License for the 3D files.

## Terminology

CC BY-NC-SA 4.0 is not an open-source license under the Open Source
Initiative's Open Source Definition, because it restricts commercial use.
What is open-sourced here is the code; the 3D assets are shared under the
author's non-commercial terms.
